# @ledgerhq/hw-ledger-key-ring-protocol

> [!NOTE]
> **Status: STABLE** — Production-ready; API is considered stable.

Hardware integration layer for Ledger Key Ring Protocol flows.

Use it with the protocol package in
[../ledger-key-ring-protocol](../ledger-key-ring-protocol/README.md).

> Low level of **Ledger Sync**. See
> [`docs/ledger-sync/01-hardware-lkrp.md`](https://github.com/LedgerHQ/ledger-live/blob/develop/docs/ledger-sync/01-hardware-lkrp.md).

Run package commands from the repository root:

```bash
pnpm --filter @ledgerhq/hw-ledger-key-ring-protocol build
pnpm --filter @ledgerhq/hw-ledger-key-ring-protocol test
pnpm --filter @ledgerhq/hw-ledger-key-ring-protocol typecheck
```
